1

System Architecture

Runtime services and integrations of the deployed application.

Highlighted: the browser runs a React single-page app served by Vercel. All state flows through React Context providers into supabase-js, which talks to Supabase Postgres guarded by Row Level Security. Sessions are JWTs issued by Supabase Auth.
Presentation layer

React Router v7 pages (public, buyer, seller, admin), Layout shells, AccessibilityToolbar, ChatWidget.

Application layer

Contexts: AuthContext (Supabase session), CartContext, DataStore, Toast, Voice. Payment provider service modules (GCash, Maya, PayMongo, Stripe, PayPal scaffolds).

Data layer

src/lib/db.js typed query wrappers over 27 im_* tables/views/RPC — every call returns {data,error}.

Infrastructure

Vercel CDN (SPA rewrites), Supabase managed Postgres + Auth, RLS policies as defense-in-depth.

10

Non-Functional Requirements

Quality attributes.

NFR-01 · Accessibility

WCAG 2.1 AA: skip link, landmarks, keyboard toolbar, high contrast, semantic cards.

NFR-02 · Security

RLS on every im_* table; anon key only in browser; mutations role-checked.

NFR-03 · Privacy

Emails masked cross-role; consent logged; no service-role key client-side.

NFR-04 · i18n

Currency ISO 4217 PHP; ISO 8601 UTC storage; en-PH display dates.

NFR-05 · Performance

Vite ESM bundles on Vercel edge CDN; images resized client-side ≤ 800px.

NFR-06 · Availability

Vercel hosting + Supabase managed Postgres/Auth.

NFR-07 · Maintainability

im_ prefix; central db.js data layer; {data,error} convention everywhere.

NFR-08 · Auditability

Activity feed + compliance audit log; exports include audit sheet.

NFR-09 · Usability

DSWD blue/red/gold tokens; admin theme customizer; toast feedback.

NFR-10 · Integrity

Stock locked & checked inside checkout RPC; FK cascade/set-null rules; amount checks.

NFR-11 · Compatibility

Evergreen browsers; responsive web only (no native app).

NFR-12 · Observability

Activity logs + Vercel deployment logs.
